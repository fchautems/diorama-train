# Asset provenance

Tous les assets 3D vendus dans ce dépôt sont issus de packs **Kenney** sous licence **CC0 1.0**. L'attribution n'est pas obligatoire, mais les sources sont conservées ici pour la traçabilité.

## Kenney Train Kit
- Source officielle: https://kenney.nl/assets/train-kit
- Licence: CC0 1.0
- Intégrés: locomotive, wagon bois, rail droit, rail courbe, colormap.
- Copie binaire récupérée depuis le miroir public GitHub `xpenatan/xpenatan.github.io`.

## Kenney City Kit (Suburban)
- Source officielle: https://kenney.nl/assets/city-kit-suburban
- Licence: CC0 1.0
- Intégrés: deux bâtiments, deux arbres, colormap.
- Copie binaire récupérée depuis `petroulacl/fps-buildings-env-kit`.

## Kenney Mini Characters
- Source officielle: https://kenney.nl/assets/mini-characters
- Licence: CC0 1.0
- Intégrés: personnage homme A, personnage femme A, colormap.
- Copie binaire récupérée depuis `irgendjemandkeinkorper/soul-meter`.

## Règle du projet
On privilégie une même famille artistique (Kenney). L'échelle est normalisée **par pack**, pas modèle par modèle, afin de préserver les proportions internes, notamment entre train et rails.
