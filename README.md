# diorama-train

Petit diorama ferroviaire 3D interactif pour le navigateur, basé sur Three.js.

## Direction visuelle

- Low-poly premium / maquette miniature.
- Priorité aux assets existants cohérents plutôt qu'à la géométrie procédurale.
- Base artistique initiale : packs 3D Kenney (CC0) pour garder une palette et un niveau de détail homogènes.
- Échelle de scène : 1 unité Three.js = 1 mètre. Les modèles importés sont normalisés à des dimensions cibles dans le code.

## Premier objectif

Construire une galerie de validation des assets avant d'assembler le diorama :
- locomotive + wagon
- rails
- 2 maisons
- 2 arbres
- 2 personnages

Voir `assets/ATTRIBUTION.md` pour les sources et licences.
